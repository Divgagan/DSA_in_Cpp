# Contributing Guide

## How to Contribute

1. Fork this repository
2. Create a feature branch: `git checkout -b feat/your-feature`
3. Add your DSA solution in the correct topic folder
4. Follow the problem documentation standard in README.md
5. Submit a pull request

## Code Style

- Use C++17 features
- Add time and space complexity comments
- Follow the template in `templates/solution.cpp`

## Commit Message Format

`feat(topic): add problem-name solution`

Example: `feat(graphs): add dijkstra shortest path`
